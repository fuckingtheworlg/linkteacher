# 公众号接入指南

LinkTeacher 小程序「我的」页底部的公众号引导卡支持两种模式：

| 模式 | 关注体验 | 主体要求 |
|---|---|---|
| **同主体（推荐）** | 一键关注按钮，无需切到公众号扫码 | 小程序与公众号属于**同一企业 / 个人主体**或已通过关联认证 |
| **非同主体** | 显示二维码，用户长按识别后关注 | 任意公众号皆可 |

---

## 一、判断你属于哪种模式

打开 [微信公众号后台](https://mp.weixin.qq.com) → 「设置 → 公众号设置 → 注册信息」，确认主体名称。
打开 [微信小程序后台](https://mp.weixin.qq.com) → 「设置 → 基本设置 → 注册信息」，确认主体名称。

- 两个**主体相同** → 同主体模式（强烈推荐，体验最好）
- 两个**主体不同** → 非同主体模式（仍可引导关注，但需用户多一步操作）

---

## 二、同主体模式接入步骤

### 1. 公众号后台：关联小程序

- 公众号后台 → 「小程序管理 → 关联小程序」
- 「添加」→ 搜索你的小程序 AppID（`wx6ed01a56fff50469`）→ 确认关联
- 关联无需小程序管理员同意（同主体直接生效）

### 2. 小程序后台：关联公众号

- 小程序后台 → 「设置 → 关联公众号」
- 「关联」→ 选择目标公众号 → 确认
- 此处用于打通用户身份（UnionID），让用户体验更连贯

### 3. LinkTeacher 后台填写配置

打开管理后台 → 左侧菜单「**公众号设置**」：

- ✅ **启用**：开
- **公众号名称**：你的公众号显示名（如「个幸话」）
- **副标题描述**：一句话简介
- ✅ **同主体**：开
- **公众号 AppID**：以 `wx` 开头的公众号 AppID（在公众号后台 → 设置 → 公众号设置 → 帐号信息）

保存。

### 4. 小程序端效果

「我的」页底部会出现微信原生的「公众号关注」卡片，用户点「关注」即可一键关注，无需离开小程序。

> ⚠️ `<official-account>` 组件需要小程序基础库 >= 2.3.0，目前所有微信版本都已覆盖。

---

## 三、非同主体模式接入步骤

如果你的公众号和小程序不是同一主体，无法使用原生组件。改为引导用户长按识别二维码。

### 1. 准备公众号二维码图片

- 公众号后台 → 「设置 → 公众号设置 → 帐号信息」
- 找到「微信号 / 二维码」一栏 → 下载二维码 PNG 图（**带边框的方形版**）
- 推荐 400×400 px 以上，避免小程序里压糊

### 2. LinkTeacher 后台填写配置

后台 → 「公众号设置」：

- ✅ **启用**：开
- **公众号名称** / **副标题描述**：与同主体一样
- ❌ **同主体**：关
- **二维码图片 URL**：
  - **点「上传图片」** 上传刚才下载的 PNG（推荐）
  - 或直接粘贴一个已有的 CDN/OSS URL

保存。

### 3. 小程序端效果

「我的」页底部出现卡片，右侧显示二维码缩略图。用户点击卡片可放大查看，长按二维码即可识别关注。

---

## 四、更换公众号

不论哪种模式，**直接在后台「公众号设置」修改保存即可**：

- 修改公众号名称 / 描述 / AppID → 立即生效（小程序下次进入「我的」页拉新配置）
- 上传新的二维码 → 自动覆盖
- 切换同主体 / 非同主体模式 → 用户下次进入「我的」页会看到新形态

**不需要重新发版**，因为公众号信息完全后台可配。

---

## 五、停用公众号卡

后台「公众号设置」→「启用」开关 → 关闭 → 保存。

小程序「我的」页不再展示该卡片，但版本号、其他模块照常。

---

## 六、常见问题

### Q1：用 `<official-account>` 组件提示「该公众号未关联本小程序」

A：去公众号后台 → 「小程序管理 → 关联小程序」补关联。**关联是双向的**：公众号 → 小程序、小程序 → 公众号 都要做，否则组件无法找到关联关系。

### Q2：二维码模式下，用户反馈无法长按识别

A：检查二维码图片是否清晰、是否带边框、用户的微信版本是否够新。安卓某些早期 ROM 上需要先点击放大，再长按才能识别。

### Q3：公众号 AppID 在哪里找？

A：公众号后台 → 「设置 → 公众号设置 → 帐号详情 → 开发者ID（AppID）」。注意**不是**小程序的 AppID。

### Q4：换公众号要不要重新审核小程序？

A：**不需要**。本小程序所有公众号信息都通过后台 SystemConfig 拉取，纯数据更换，无需重新发版。
